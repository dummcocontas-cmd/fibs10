🚗 Guia Rápido

Sistema de Controle S10 - Instalação em 5 minutos

1

Criar Projeto no Firebase

Acesse o Firebase Console e crie um novo projeto

🔗 Abrir Firebase Console

Dica: Use um nome descritivo como "controle-s10-empresa"

2

Ativar Firestore Database

Configure o banco de dados em tempo real

  1. No menu lateral, clique em "Firestore Database"
  2. Clique em "Criar banco de dados"
  3. Selecione "Iniciar no modo de produção"
  4. Escolha localização: southamerica-east1 (São Paulo)
  5. Clique em "Ativar"
3

Configurar Regras de Segurança

Permita acesso ao banco de dados

  1. Vá em Firestore Database > Regras
  2. Copie e cole o código abaixo
  3. Clique em "Publicar"
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
4

Obter Credenciais do Firebase

Copie as configurações do seu projeto

  1. Clique no ícone de engrenagem ⚙️ > Configurações do projeto
  2. Role até "Seus aplicativos"
  3. Clique no ícone </> (Web)
  4. Registre o app (ex: "controle-s10-web")
  5. Copie o objeto firebaseConfig

⚠️ Importante: Guarde essas credenciais! Você precisará delas no próximo passo.

5

Configurar Arquivos HTML

Substitua as credenciais nos arquivos do sistema

📝 Edite estes 4 arquivos:

  • index.html
  • funcionario.html
  • admin.html
  • setup-funcionarios.html

Em cada arquivo, procure por:

const firebaseConfig = {
    apiKey: "SUA_API_KEY_AQUI",
    authDomain: "SEU_PROJETO.firebaseapp.com",
    projectId: "SEU_PROJETO_ID",
    ...
};

E substitua pelas credenciais que você copiou no passo 4.

6

Cadastrar Funcionários

Configure os 20 funcionários que usarão o sistema

  1. Abra o arquivo setup-funcionarios.html no navegador
  2. Cadastre os funcionários um por um OU
  3. Cole a lista completa (formato: Nome, Setor)
  4. Clique em "Cadastrar Lista Completa"
7

Hospedar no GitHub Pages

Publique o sistema online gratuitamente

  1. Crie um repositório no GitHub
  2. Faça upload de todos os arquivos HTML
  3. Vá em Settings > Pages
  4. Selecione main branch como source
  5. Clique em Save

✨ Pronto! Seu sistema estará disponível em:
https://seu-usuario.github.io/controle-s10/

8

Criar QR Code

Facilite o acesso dentro da S10

  1. Acesse QR Code Generator
  2. Cole a URL do seu sistema
  3. Baixe o QR Code
  4. Imprima e cole dentro da S10

💡 Dica: Cole o QR Code em um local visível, próximo ao volante!

🎉 Parabéns!

Seu Sistema de Controle S10 está pronto para uso!
